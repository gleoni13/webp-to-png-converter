# WebP to PNG Converter

A lightweight Python script that automatically converts all `.webp` images in its current directory into `.png` format using Pillow.

## Features

- **Batch Conversion**: Scans the script's directory and processes all `.webp` files in one go.
- **Directory Auto-Focus**: Automatically sets its working directory to the script location.
- **Console Feedback**: Displays real-time progress for each converted image.

## Prerequisites

- Python 3.7+
- Pillow library
