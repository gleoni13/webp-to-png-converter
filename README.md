# WebP to PNG Converter

A lightweight Python script that automatically converts all `.webp` images in its current directory into `.png` format using Pillow.

## Features

- **Batch Conversion**: Scans the script's directory and processes all `.webp` files in one go.
- **Directory Auto-Focus**: Automatically sets its working directory to the script location.
- **Console Feedback**: Displays real-time progress for each converted image.

## Prerequisites

- Python 3.7+
- Pillow library

## Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/webp-to-png-converter.git](https://github.com/your-username/webp-to-png-converter.git)
   cd webp-to-png-converter
   ```

## 💡 Usage Guide

### 1. Batch Image Downloader (`website_image_downloader.py`)
1. Place the `webp_to_png_converter.py` file into the folder containing your `.webp` images.
2. Run the script:
   ```python
   python webp_to_png_converter.py
   ```
3. The converted `.png` files will be saved in the same directory.
